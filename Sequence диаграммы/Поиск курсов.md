```plantuml
title "GET /courses/search?filter="python""

actor user as "Пользователь"

participant apiGateway as "API Gateway"
participant coursesService as "Сервис курсов"
database coursesService_db as "БД сервиса курсов"

user ->> apiGateway++: Поисковый запрос по ключевому слову

apiGateway ->> coursesService++: Поисковый запрос по ключевому слову
coursesService -> coursesService_db++: Запрос в БД записей, в которых в названии курса содержится ключевое слово
alt Успешный запрос
    coursesService <-- coursesService_db: Таблица с релевантными записями
    apiGateway <<-- coursesService: Ответ со списком курсов
    user <<-- apiGateway: Ответ со списком курсов
else Нет курсов с таким названием
    coursesService <-- coursesService_db--: Пустая таблица
    apiGateway <<-- coursesService--: Ответ "курсов с таким названием нет"
    user <<-- apiGateway--: Ответ "курсов с таким названием нет"
end


```
